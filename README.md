# learn-llm

Привет! 👋 Я Настя, Data Scientist и TeamLead. Здесь я разбираю книгу Себастьяна Рашки «Строим LLM с нуля» (Build a Large Language Model (From Scratch)) — глава за главой, с кодом и экспериментами.

Это не копия кода из книги. Оригинал лежит в [репозитории автора](https://github.com/rasbt/LLMs-from-scratch). Здесь мои эксперименты в тех местах, где мне было мало «просто поверить»: хотелось проверить руками и увидеть в цифрах. Почти к каждому эксперименту есть статья на Хабре.

Список будет расти вместе с книгой.

## Как запустить

```bash
git clone https://github.com/<логин>/learn-llm.git
cd learn-llm
pip install -r requirements.txt
jupyter notebook
```

Ноутбуки лежат в папках глав. Для большинства хватит `numpy` и `matplotlib`, GPU не нужен.
